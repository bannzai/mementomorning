# Handoff: Memento Morning — 全画面デザイン & プロトタイプ

## Overview
「毎朝『今日死ぬとしたら、何をやりたいか』に答えてアラームを止める」iOS アプリの全画面デザイン。
禅・ミニマリズム・余白・タイポグラフィ中心の「静かな世界観」。ゲーミフィケーション記号(炎・バッジ・紙吹雪)は一切使わない。streak の代わりに「人生カレンダー(週グリッド)に答えた朝が点として残る」表現を使う。

対象リポジトリ: `bannzai/mementomorning`(iOS 26+ / SwiftUI / AlarmKit / SwiftData / RevenueCat)。

## About the Design Files
このフォルダの `.dc.html` / `.jsx` は **HTML で作られたデザインリファレンス**です(見た目と挙動の仕様を示すプロトタイプ)。そのまま出荷するコードではありません。
実装タスクは、これらのデザインを **対象コードベース(SwiftUI)の既存パターンで再現する**ことです。既存の Feature 構成(`MementoMorning/Features/...`)・SwiftData モデル(`MorningAnswer`, `AlarmSetting`)・ローカライズ規約(`.claude/rules/localization-guidelines.md`)に従ってください。

## Fidelity
**High-fidelity**。色・タイポ・字間・余白・コピーは最終意図。SwiftUI では px 値を pt として概ね 1:1 で再現してよい(モックは 390×844 / プロトタイプは 402×874 基準)。
日本語・英語の両方でレイアウトが崩れないこと(モックは日英併記で検証済み)。

## Design Tokens
### 色(ダークモード前提・唯一のテーマ)
- 背景(墨): `#0B0C0E`
- 前景(温白): `#E9E7E2`
- 二次テキスト: `rgba(233,231,226,0.55)` / 三次: `0.40` / 微弱: `0.30–0.35`
- ヘアライン(区切り線): `rgba(233,231,226,0.07–0.08)`
- アクセント(夜明けの微光): `#C2A183` — **各画面 1 箇所まで**(節目ラベル、今日の粒のリング、キャレット等)
- 点(回答済み): `#E9E7E2` / 未回答: `rgba(233,231,226,0.09)` / 今日のリング: `0 0 0 3px rgba(194,161,131,0.35)`
- 共有カードのみ: 背景 `#000` / 文字 `#FFF`
- 派手な色・彩度の高い色は使わない。エラー等も低彩度で。

### タイポグラフィ(サンセリフ中心)
- フォント: SF Pro(-apple-system)+ Hiragino Sans。SwiftUI では `.system` + 適切な `weight`
- 大時刻(ホーム): 96pt / weight 200(ultraLight)
- 問いオーバーレイ: 27pt / weight 300(light)/ line-height 1.65 / letter-spacing 0.05em
- 回答本文(文字起こし・夜): 25–26pt / 300 / line-height 1.8
- 画面タイトル: 15pt / 500 / letter-spacing 0.14em
- 英語サブラベル: 9–11pt / letter-spacing 0.2–0.26em / 40% 白(「NEXT MORNING」等の大文字トラッキング)
- 本文リスト: 14–17pt / 300
- 注釈: 10–12pt / 30–45% 白
- 共有カードのみセリフ体(実装済み `AnswerShareCardView.swift` に準拠)

### 形・余白
- ボタン: 全て pill(`border-radius: 999`)。primary = 温白地に墨文字 / secondary = ヘアライン枠のみ。padding 15–17pt 縦
- 画面左右マージン: 32–36pt。ヒットターゲット 44pt 以上
- 影・カード・角丸コンテナは基本使わない。区切りはヘアラインのみ
- アイコンはほぼ使わない(SF Symbols も最小限)。粒・円・線だけで構成

## Screens / Views

### 1. ホーム(`1e` / プロトタイプ home)
- 中央: ラベル「次の朝 · NEXT MORNING」(10pt, 0.26em) → 大時刻 5:50(96pt/200, タップでアラーム設定へ) → 「あと n 時間 m 分 · 時刻をタップして変更」(12pt/40%)
- トグル: 56×34 pill。ON 背景 `rgba(194,161,131,0.45)`、ノブ 28pt 温白、0.3s ease
- 回答済みの日のみ: 「今朝のことば」ラベル(#C2A183)+ 回答テキスト + 「直す」(下線リンク風) → 編集画面へ
- 下部: 直近 14 日の粒ストリップ(10pt 粒, gap 8)+「答えた朝 N」+ テキストリンク行(ジャーナル / 人生カレンダー / 設定)

### 2. 朝の問い(コア画面, `1a` 採用案 / プロトタイプ question)
- 全面: インカメラプレビュー(実装ではカメラ映像)。モックは `radial-gradient(130% 90% at 50% 38%, #26282C → #16171A 55% → #0B0C0E)`
- スクリム: 上 `rgba(11,12,14,0.72)→0` (0–42%)、下 `0→0.78` (62–100%)。**明るい寝室でも問いが読めることが要件**(text-shadow `0 1px 24px rgba(11,12,14,0.6)` 併用)
- 問い: 上部中央 27pt/300、下に英訳 11pt/50%
- 録画ボタン: 84pt 外リング(1.5pt, 85% 白)+ 内円 64pt 温白。録画中は内側が 34pt の角丸四角(radius 8)に 0.35s で変形(SNS 的な赤 REC は使わない)
- 録画中: 右上に 6pt の点(ゆっくり明滅 1.6s)+ mono 数字タイマー `0:12`。ラベルは「止めると、アラームも止まります」
- ラベル: 「話して、答える / SPEAK YOUR ANSWER」。下に「キーボードで答える」(下線・代替入力)
- 録画停止 → 動画を写真アプリへ保存 + 音声を文字起こし → 文字起こし確認へ

### 3. 文字起こし確認(`1d` / プロトタイプ transcribe)
- 変換中: 中央に #C2A183 の点(明滅)+「ことばにしています」(13pt/0.16em)
- 確定前: ラベル「今朝のことば · TRANSCRIPT」+ 日時 → 回答テキスト 26pt/300/1.8(編集可、キャレット #C2A183) → 注釈「音声から書き起こしました。テキストをタップすると直せます。」
- ボタン: primary「これで確定する」/ テキスト「音声でもう一度」(→ 問い画面へ戻る) / 注釈「動画は写真アプリに保存されました」
- **編集モード(当日のみ)**: 同一画面の再利用。タイトル「今朝のことばを直す · EDIT」、ボタン「これで直す」。ホームとジャーナルの「直す」から遷移。過去日の回答は編集不可

### 4. ジャーナル(`1f` / journal)
- タイトル「ジャーナル / JOURNAL」中央
- 行: 日付(11pt/38%)+ 回答(17pt/300)。ヘアライン区切り。今日の行は日付が #C2A183 で右端に「直す」。過去行は右端に夜の結果(「やれた」/「—」)
- 行タップ: 今日 → 編集 / 過去 → 共有カード
- 無料は直近 7 日。末尾に「7日より前の朝は、プレミアムで。/ すべての朝を見る(#C2A183)」→ ペイウォール

### 5. 人生カレンダー(`1g` / calendar)
- 7 列グリッド(1 行 = 1 週)。粒 13pt 円、gap 11pt
- 塗り: 回答済み = 温白 / 未回答 = 9% 白 / 今日 = #C2A183 リング
- コピー: 「1行が一週間。答えた朝が、点として残る。」/ 下部「答えた朝 N」「点は、いつかつながる。」(streak 修復は作らない)
- 実装は既存 `lifeCalendarDays()`(最低 13 週、最初の回答週〜今週)を使用

### 6. 節目(静止案のみ: `1h` 七つの朝 / `1i` 90日 問い直し / `2e` 30日 一ヶ月の手紙)
- 共通: 上部に #C2A183 のラベル「7日目の朝に」等(10pt/0.24em)。大タイトル 25–30pt/300
- 七つの朝: 01–07 の mono 番号 + 回答 7 行。下部 secondary ボタン「この七日を、一枚に」
- 問い直し(90日): 「あなたの答えは、変わりましたか。」+ 左右 2 カラム(1日目 | 90日目, 中央に縦のフェードするヘアライン)。90日目ラベルのみ #C2A183。下部リンク「そのまま、今日の問いへ」
- 一ヶ月の手紙(30日): 手紙形式の文章 + 署名「— Memento Morning」+「手紙を閉じる」

### 7. 夜の振り返り(`1j` / night)
- 21:30 の通知(本文に今朝の回答を引用)から開く
- 「守れてますか? / ARE YOU KEEPING IT?」→ 今朝の回答 25pt/300 → 「今朝 5:50 のあなた · 動画を見返す」(動画再生導線)
- ボタン: primary「やれた」/ secondary「やれていない」+ 注釈「空白は空白のまま残ります」

### 8. 共有カード(`1k` / share)— 実装済み `AnswerShareCardView.swift` 準拠
- 360×360pt(ImageRenderer scale 3 → 1080px)。黒地・白文字・**セリフ体**
- 上: 問い 12–13pt/60% → 中央: 回答 24pt/500(minimumScaleFactor 0.5) → 下: 日付 12pt/60% + 「Memento Morning」11pt/35%/0.15em

### 9. ペイウォール(`1l` / paywall)
- 「すべての朝を、残すために。/ KEEP EVERY MORNING」
- 機能 4 行(ヘアライン区切り、各行タイトル 14pt + 説明 11pt/40%): 無限追撃アラーム=答えるまで、鳴りやまない / すべての履歴 / 30・90・180日の節目 / 問いのデッキ
- primary「年 ¥3,600(ひと月 ¥300)」/ secondary「月 ¥480」/ テキスト「今はしない」
- 注釈「いつでも解約できます。回答はこの端末に残ります。」バッジ・カウントダウン等の圧は一切なし

### 10. アラーム・通知設定(プロトタイプ alarm)
- タイトル「アラーム / ALARM & REMINDERS」
- 時刻: 64pt/200 表示 + 左右に −/＋(44pt 円ボタン, 1h 単位)+ 下に −5分/＋5分 pill
- リスト(ヘアライン区切り): アラーム(トグル)/ スヌーズ「2回まで(無料)」/ 無限追撃アラーム(無料時は右端「プレミアム」#C2A183 → ペイウォール、課金済みはオン/オフ)/ 夜のリマインド 21:30
- 注記: 「アラームの停止画面は iOS 標準のままです。停止すると、この問いの画面が開きます。」(AlarmKit 制約)
- 下部 primary「保存して戻る」

### 11. オンボーディング(`1m`, 静止案)
- 「死を想ってから、朝を始める。」29pt/300/line-height 1.85 + 英訳 + 説明 2 行
- 下部 300pt に夜明けグラデーション `rgba(194,161,131,0)→0.22` + 地平線 1pt ライン(中央が最も明るい linear-gradient)
- primary「はじめる」+ 注釈「次の画面でアラームと通知の許可をお願いします」

## Interactions & Behavior
- 画面遷移: 0.5–0.7s のフェードのみ(スライド・バウンス等は使わない)。ハプティクスは録画開始/停止・確定・やれた/やれていないに軽い `.soft` / `.rigid` を推奨
- 朝のフロー: アラーム停止(AlarmKit stopIntent, `openAppWhenRun = true`) → 問い → 録画 → 文字起こし → 確定 → 追撃アラーム全キャンセル → ホーム(回答済み状態)
- 録画ボタン: 円⇄角丸四角のモーフ 0.35s。録画中の明滅は 1.4–1.6s 周期のゆっくりした opacity 0.25⇄0.8
- 確定は空文字では無効。編集は当日分のみ
- ジャーナルのロック行タップ / 設定の「無限追撃」タップ(未課金時) → ペイウォール。購入成功 → 元の画面へ戻る
- 夜の通知から night 画面。回答が無い日は既存実装どおり「今朝の回答はまだありません」+ 閉じる

## State Management
- `AlarmSetting`(既存 SwiftData): hour / minute / isEnabled(+ 将来: 追撃オン/オフ)
- `MorningAnswer`(既存): answeredDate / text / isFulfilled(+ 動画のローカル識別子、文字起こし元フラグ)
- 画面状態: 録画中(経過秒)/ 文字起こし中 / 編集モード(当日のみ) / プレミアム entitlement(RevenueCat)
- 無料 7 日制限は既存 `AnswerLogVisibility.isVisible` を使用
