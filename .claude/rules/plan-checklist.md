# Plan ファイルチェックリスト

Plan mode では、以下のチェックリストから変更対象に該当するセクションをプランファイル末尾に追記する。

## チェックリスト

### 実装内容
- [ ] 変更対象ファイルごとに具体的なコード提案をコードブロックで記載している
- [ ] 既存コードのパターン・構成を確認し、同じパターンで実装している
- [ ] 変更範囲が必要最小限であること

### ビルド・テスト（ビルドシステムに変更がある場合）
- [ ] ビルドが成功する
- [ ] 既存テストが全件パスする
- [ ] 新規・変更機能に対するテストが存在する（なければ新規作成）

### iOS / SwiftUI（Swift コードに変更がある場合）
- [ ] シミュレータビルドが成功する（AGENTS.md「検証方法」の手順でログを検査する）
- [ ] ユニットテストが全件パスする（時刻依存ロジックは Date 注入でテストする）
- [ ] AlarmKit API は `#available(iOS 26.0, *)` でガードされている
- [ ] SwiftData モデルの変更は `.claude/rules/swiftdata-guidelines.md` / `.claude/rules/coding-rules-entity.md` に準拠している

### 動作確認（UI・挙動に変更がある場合）
- [ ] AGENTS.md の「検証方法」に従い、/ios-simulator 経由 (simtunnel) のシミュレータで動作確認する（アラーム発火の確認方法も同セクションに従う）
- [ ] UI 変更はスクリーンショットで描画を確認してから完了報告する

### 共通
- [ ] エラーメッセージはそのまま表示（加工・プレフィックス除去なし）
